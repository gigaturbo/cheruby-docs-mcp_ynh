From a folder

A recording in one of your folders, by its path, as the agents name it. An hour of audio takes up to an hour on this server; the page can be closed meanwhile, and what is done is kept.

From this device

A recording sent from here, up to 500 MB: mp3, m4a, aac, wav, ogg, opus, flac, webm, mka, amr, 3gp or mp4. It is not kept in your folders; its text is, here, for 30 days.

Index schedule

A file added or changed is found by meaning after the next run. Each run reads only the files that changed. A change here applies at once.

Cron's five fields: minute, hour, day, month, weekday. 20 * * * * runs at :20 every hour; 0 12 * * mon-fri at noon on weekdays; */30 8-20 * * * every half hour from 08:00 to 20:30. A day of the month and a weekday cannot both be set.

From one hour to another, the second excluded, such as 01-06 or 22-07. No run starts then, and a run still going stops when they begin and carries on at the next run. Run now in the config panel ignores them. 01-06 keeps clear of the nightly backups, 01:30 to about 05:45. Empty for none.

Filters

Per source, which files the agents and search see. One pattern per line. *.pdf or Factures match any name; Documents/Factures matches from the folder on. Case is ignored, and * crosses folders. What a filter leaves out is not listed, found, read nor searched, at once; the next run drops it from the index.
