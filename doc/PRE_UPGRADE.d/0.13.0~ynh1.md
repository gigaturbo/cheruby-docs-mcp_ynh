From 0.13.0, the app has a page, so it needs a web address. An install from
before 0.13.0 has none, and YunoHost stops the upgrade without one. Set it
once, before upgrading, to a domain of this server and a path no other app
uses. The first command must print `True`:

```bash
sudo yunohost domain url-available <domain> /docs
sudo yunohost app setting cheruby-docs-mcp domain -v <domain>
sudo yunohost app setting cheruby-docs-mcp path -v /docs
```

Only the user chosen in the config panel may open the page.
